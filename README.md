# 头像大乱斗 ⚔️

上传你的微信头像 → 本地鉴定出**五行属性、五维属性、称号、战斗力** → 与好友头像 PK，看谁的头像能打。

> 纯前端实现，零服务器成本。头像只在浏览器本地分析，不上传任何数据。

## 一、鉴定机制（头像 → 属性）

对头像降采样到 64×64 后做像素统计，**同一头像结果永远一致**（这是传播点："我的头像天生 8000 分"）。

| 头像特征 | 分析方法 | 决定什么 |
|---|---|---|
| 色彩饱和度 | 全像素饱和度均值 | 攻击（色彩越浓烈越凶） |
| 左右对称性 | 镜像差异度 | 防御（构图越稳越抗揍） |
| 细节密度 | 相邻像素亮度梯度 | 速度（画面越"满"越快） |
| 色彩丰富度 | 色相直方图分布 | 技巧（颜色越多越会玩） |
| 图像哈希 | FNV-1a 哈希 | 运气（纯玄学，换头像=重摇） |
| 主色调 | 色相分桶统计 | 五行属性 |

### 属性判定

- **五行**：红橙→火，黄金→金，绿→木，蓝青→水，棕褐→土（按占比最大者）
- **⚡隐藏属性·雷**：高饱和紫色像素占比 > 16% 触发（稀有，约 5% 头像）
- **🌀隐藏属性·混沌**：灰度像素占比 > 78% 触发（黑白头像专属，全属性 +3，伤害波动巨大）

## 二、PK 机制

### 五行相克

金克木 → 木克土 → 土克水 → 水克火 → 火克金；**雷**克水、金，被土克；混沌与世无争。

克制伤害 ×1.3（触发"克制!"横幅），被克 ×0.72。

### 数值规则

- 生命 = 80 + 防御 × 1.8
- 伤害 = 攻击 × 浮动(0.85~1.15) × 克制系数 × (1 − 防御/(防御+130))
- 速度：决定出手顺序；快 15 点以上有 18% 概率**追击**
- 技巧：决定技能触发率（8% + 技巧×0.4%）
- 运气：决定暴击率（×1.7）与闪避率

### 每个五行一个专属技能

| 属性 | 技能 | 效果 |
|---|---|---|
| 🔥火 | 烈焰冲撞 | ×1.55 伤害 + 灼烧（下两次行动各掉 5% 血） |
| ⚔️金 | 破甲一击 | ×1.5 伤害且无视 30% 防御 |
| 🌿木 | 荆棘缠绕 | ×1.25 伤害 + 敌方下次攻击减弱 30% |
| 💧水 | 治愈之泉 | 回复 14% 生命 + 追加 60% 拍击 |
| ⛰️土 | 大地壁垒 | 获得 12% 生命护盾 + 80% 撞击 |
| ⚡雷 | 天雷引 | ×1.2 伤害 + 40% 概率追加一击 |
| 🌀混沌 | 混沌波动 | ×1.8 伤害，但 25% 概率"失稳"落空 |

战斗过程由双方头像哈希做种子，**同两个头像 PK 结果恒定**——不服就换头像。

## 三、演出与头像内容的关联

- **头像本体就是战士**：冲锋、撞击、挨打闪红、被击飞——你的头像亲自挨揍
- 技能特效按头像五行渲染：火头像喷火粒子、水头像泛蓝波纹、雷头像劈紫电
- 克制瞬间有专属横幅演出，暴击有放大数字
- 战斗结束生成**战报卡片**（称号/战力/总输出/暴击数），可复制发朋友圈

## 四、目录结构（核心与平台适配分离）

```
avatar-brawl/
  index.html            入口 + 样式（H5 适配层）
  js/core/data.js       元素/称号/工具函数（纯数据，各平台通用）
  js/core/analyzer.js   头像像素分析器（纯逻辑，各平台通用）
  js/core/battle.js     战斗模拟器（纯逻辑，各平台通用）
  js/ui/appraisal.js    鉴定报告演出（Canvas）
  js/ui/battleScene.js  战斗演出（Canvas）
  js/main.js            H5 主流程（文件上传/存储/BOSS生成）
```

core/ 三个文件不做任何修改即可移植到微信小游戏，只需重写 UI 层和 main.js。

## 五、运行

```bash
cd avatar-brawl
python3 -m http.server 8765
# 打开 http://localhost:8765
```

（双击 index.html 直接打开也能玩。）
